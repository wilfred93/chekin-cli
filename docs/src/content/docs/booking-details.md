---
title: Booking details and guest links
description: Show one booking with its guest check-in, payment and upsell links and its dashboard URL, or add the links to a whole list.
---

## Show one booking

Pass a booking ID from [`chekin bookings list`](/chekin-cli/bookings/):

```sh
chekin bookings get a1b2c3d4
```

```text
ID:             a1b2c3d4
Check-in:       2026-11-07
Check-out:      2026-11-14
Nights:         7
Guest:          -
Status:         NEW
Source:         Airbnb
External ID:    HMABC12345
Price:          420.00 EUR
Check-in link:  https://guest.chekin.com/AbC123x
Payment link:   https://guest.chekin.com/DeF456y
Upsell link:    https://guest.chekin.com/GhI789z
Dashboard:      https://dashboard.chekin.com/bookings/a1b2c3d4
```

Fields the booking doesn't have show as `-`. If the ID doesn't exist, `chekin` prints
`error: booking <id> not found` and exits with `1`.

## The links

| Link | What it's for |
| --- | --- |
| Check-in link | The guest's online check-in form. Send it to guests who haven't registered yet. |
| Payment link | Where the guest pays any pending amount (deposit, tourist tax…). |
| Upsell link | The guest's page for extras you offer. |
| Dashboard | Opens the booking in the Chekin dashboard. You need to be logged in there. |

Guest links look like `https://guest.chekin.com/<code>`. Each code is generated by Chekin and unrelated to
the booking ID, so `chekin` has to fetch them from the API. The dashboard URL is always
`https://dashboard.chekin.com/bookings/<booking-id>`.

## Full booking as JSON

```sh
chekin bookings get a1b2c3d4 -o json
```

This prints the full booking as the API returns it, about 85 fields, plus a `dashboard_url` field added by
`chekin`. The links are in `signup_form_link`, `payment_link` and `upselling_link`. See
[Output formats](/chekin-cli/output/).

```sh
chekin bookings get a1b2c3d4 -o json | jq -r .signup_form_link
```

## Links for many bookings

`chekin bookings list --links` fetches the details of every booking in the list and adds:

- a `CHECK-IN LINK` column to the table;
- `signup_form_link`, `payment_link`, `upselling_link` and `dashboard_url` fields to each booking in `json`
  and `jsonl` output.

```sh
chekin bookings list --upcoming --status incomplete --links
```

```text
ID        CHECK-IN    CHECK-OUT   PROPERTY       GUEST  GUESTS  STATUS      SOURCE  CHECK-IN LINK
a1b2c3d4  2026-11-07  2026-11-14  Sea view flat  -      0/2     INCOMPLETE  Airbnb  https://guest.chekin.com/AbC123x
```

This makes one extra request per booking (five at a time), about 20 seconds for 128 bookings. Use filters or
`--limit` to keep the list short. If any of the requests fails, the whole command fails.
