The contribution guide is
[CONTRIBUTING.md](https://github.com/wilfred93/chekin-cli/blob/master/CONTRIBUTING.md) in the repository.
It covers:

- running the tests and the CLI from source;
- regenerating the [command reference](/chekin-cli/reference/commands/) after changing a command;
- previewing this site;
- finding and adding a dashboard endpoint without leaking tokens or guest data;
- the docs style guide;
- making a release.

## Report a problem

[Open an issue](https://github.com/wilfred93/chekin-cli/issues/new/choose) with the command you ran and the
error. Leave out your token and any guest names, emails or booking IDs.
